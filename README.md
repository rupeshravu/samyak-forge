Build a premium, futuristic multi-page website for **SAMYAK**, a large-scale college cultural/technical fest. The site should feel like an exclusive international festival experience — dark, cinematic, sci-fi-inspired — not a generic event template.




## Tech Stack

- React + Vite + Tailwind CSS

- Reusable, well-organized components

- Framer Motion (or similar) for scroll/reveal/parallax animations

- Fully responsive: desktop, laptop, tablet, mobile

- Accessible forms/buttons, SEO-friendly structure, optimized images




## Visual Style

- Deep black/navy background with subtle grain/texture

- Dominant glowing red, crimson, orange, and warm-white accents

- High-contrast, bold editorial typography (large display headlines, thin body text)

- Thin borders, fine-line dividers, minimal UI chrome

- Subtle glassmorphism only — avoid generic card-heavy layouts

- Floating particles, glowing dust/smoke, ambient animated backgrounds

- Large cinematic imagery integrated into asymmetric, magazine-style layouts

- Smooth scroll animations, parallax movement, cinematic page transitions

- Custom cursor/glow effect, magnetic buttons, navbar that transforms on scroll

- Animations should feel smooth and premium — never distracting




Use placeholder images/content wherever real SAMYAK data isn't provided, but structure everything so it's easy to swap in real content later.




## Global Navigation

Fixed, transparent navbar (solidifies on scroll) with:

**SAMYAK logo | About | Events | Registration | Team | Sponsors | Login**

Plus a glowing red **Register Now** button (outline that fills on hover).

On mobile: collapses into a hamburger menu, keeps the cinematic look.

## PAGE 1 — HOME




**Hero (full-screen, immersive)**

- Large cinematic background with dramatic red/orange futuristic lighting, floating particles

- "SAMYAK" + tagline "THE ULTIMATE CAMPUS EXPERIENCE"

- Short festival description

- Event date, venue, live countdown timer

- "Explore Events" and "Register Now" buttons




**About SAMYAK**

- Editorial layout (asymmetric grid, image blocks, thin red timeline lines)

- Intro, vision, mission, festival experience, number of events, expected participants, past editions




**Event Highlights**

- Editorial grid (not repetitive cards) across categories: Technical, Cultural, Gaming, Creative, Workshops, Competitions

- Each: name, category, short description, date/time, "View Details" button




**SAMYAK Journey (vertical timeline)**

- Concept → Preparation → Events → Grand Celebration → Closing

- Glowing red vertical line with animated nodes as user scrolls




**Gallery**

- Immersive, mixed-size overlapping image layout with hover animations

- Categories: past moments, performances, competitions, crowd shots, workshops, behind-the-scenes




**Why SAMYAK? (stats)**

- Large animated counters: 100+ Events, 10K+ Participants, 50+ Colleges, Multiple Experiences




**Closing CTA**

- Full-width dramatic section: "READY TO BE PART OF SAMYAK?"

- "Register Now" and "Explore Events" buttons
